# React 기초과정

이 저장소는 React 기초부터 백엔드 연동, UI 블록 실전, 캡스톤 프로젝트 만들어보기까지 단계적으로 학습하는 강의 자료입니다.

## 자신의 로컬 컴퓨터로 복사하기 (clone)

```bash
cd ~   # 또는 원하는 폴더. 주의: 이 폴더의 아래에 하위폴더로 생성됨
git clone https://github.com/ValleyJin/react_basic.git
cd react_basic
```


## 2) 본 과정의 목적

- React의 핵심 개념(JSX, 컴포넌트, 상태, 라우팅)을 단계적으로 익힌다.
- "프론트 단독 개발"에서 "서버/DB 연동"으로 넘어가는 실무 흐름을 경험한다.
- 같은 도메인(BeanLog 카페)을 반복 확장하며 설계 감각과 재사용 패턴을 익힌다.
- 최종적으로 풀스택 캡스톤과 UI 블록 조립(Next.js + shadcn)까지 연결한다.

## 3) lesson 범위 (개조식)

1. React 프론트앤드 기초: `lesson-01` ~ `lesson-06`

    - (선택) 프론트앤드 확장: `lesson-11`
3. DB 심화: `lesson-12` ~ `lesson-14`
    - (선택) 캡스톤 프로젝트: `lesson-15`

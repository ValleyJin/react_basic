# 11강 — Zustand로 클라이언트 전역 상태 (선택 확장)

**상세 강의(이론·단계별 실습·용어·트러블슈팅):** 이 폴더 루트의 **`강의.md`** 를 연다.

**테마(라이트/다크)** 와 **장바구니**를 서버 없이 브라우저 전역으로 관리하는 예제이다.  
10강(TanStack Query·**서버 상태**)과 짝을 이루도록, 여기서는 **클라이언트 전역 상태**만 다룬다.

## 선행

- 5강(라우터), 2~3강(state) 정도면 충분하다. 10강을 들었으면 “서버 vs 클라이언트 상태” 비교가 쉽다.

## 실행

```bash
cd lesson-11-zustand-client-state
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` — **메뉴 담기**에서 담고, 상단 **장바구니 배지**와 **다크 모드**를 확인한다. 새로고침 후에도 유지되는지 본다.

자세한 이론·코드 지도는 **`강의.md`** 를 본다.

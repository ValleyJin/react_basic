# 5강 — 라우팅으로 “한 사이트”처럼 만들기

## 이번 강의에서 배우는 것

- **`react-router-dom`**: URL 경로에 따라 다른 페이지 컴포넌트를 보여준다
- **`Routes` / `Route`**: 경로와 컴포넌트를 매핑
- **`Outlet`**: 공통 레이아웃 안에서 “자식 페이지”가 들어갈 자리
- **`NavLink`**: 내비게이션 링크 + 현재 경로 강조(`active`)
- **`Link`**: 페이지 전환(새로고침 없이 클라이언트 라우팅)

## 1~4강과 어떻게 이어지나?

- 1강의 **정적 소개**는 `HomePage`로 옮겼습니다.
- 3~4강의 **메뉴 CRUD + localStorage**는 `MenuPage`에 모았습니다.
- 4강의 **문의 폼**은 `ContactPage`로 분리했습니다.

즉, 기능은 이전 강의와 같은 계열이고, **파일 구조만 “페이지 단위”로 나뉜 상태**입니다.

## 라우팅에서 자주 하는 실수

- `BrowserRouter`는 보통 **한 번만** 감쌉니다(여기서는 `main.jsx`).
- `NavLink`에 `end` prop: `/` 홈 링크가 다른 경로에서도 활성으로 남는 문제를 막을 때 자주 씁니다.

## 배포 시 참고(심화)

Vite로 빌드한 정적 사이트를 “서브 경로”에 올리면 `basename` 설정이 필요할 수 있습니다.  
(교육용 로컬 실행에서는 기본 설정으로 충분합니다.)

## 자습 체크리스트

- [ ] 주소창에 `/menu`, `/contact`를 직접 입력해도 원하는 화면이 뜨는지 확인
- [ ] `MenuPage`에서 메뉴를 바꾼 뒤 `HomePage`로 이동했다가 다시 와도 데이터가 유지되는지 확인(localStorage)
- [ ] “404 페이지”를 하나 추가해 보기(선택: `path="*"`)

## 실행 방법

```bash
cd lesson-05-router-site
npm install
npm run dev
```

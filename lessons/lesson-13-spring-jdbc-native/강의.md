# 13강 — Spring `JdbcTemplate`과 원시 SQL (스타일 B)

> **위치:** 본 강 전체는 **`lesson-13-spring-jdbc-native/강의.md`** 에 있다.  
> **선행:** 12강(SQL)·7~9강(Spring Boot + Postgres) 중 하나 이상.  
> **이 강에 없는 것:** JPA 엔티티, Repository — 의도적으로 제외했다.

---

## 1. 이번 강의에서 배우는 것

- **`JdbcTemplate`** 으로 **문자열 SQL**을 실행하고, `RowMapper` / `queryForObject` 로 결과를 자바 객체·맵으로 받기
- **`schema.sql` / `data.sql`** 을 이용한 초기 스키마·데이터 적재 (Boot의 SQL init)
- 9강에서 본 **JPA 중심** 흐름과 **언제 원시 SQL을 고를지** 비교하는 시각

---

## 2. 왜 JPA 없이 JDBC만 쓰나

| 상황 | 흔한 선택 |
|------|-----------|
| CRUD·도메인 모델이 명확 | JPA 등 ORM |
| 복잡한 리포트·집계·DB 고유 함수 | `JdbcTemplate`, 또는 네이티브 쿼리 |

교육용으로 **의존성을 JDBC만** 두어, SQL 문자열이 어디로 가는지 한눈에 보이게 했다.

---

## 3. 프로젝트 구조

| 경로 | 역할 |
|------|------|
| `pom.xml` | `spring-boot-starter-jdbc` — **data-jpa 없음** |
| `application.yml` | DataSource, `spring.sql.init.mode: always` |
| `schema.sql` | `menu_sales` 테이블 |
| `data.sql` | 샘플 매출 행 |
| `SalesJdbcController` | `/api/jdbc/totals-by-item`, `/api/jdbc/row-count` |
| `docker-compose.yml` | Postgres, 호스트 포트 **5436** |

---

## 4. 따라 하기

1. `docker compose up -d`
2. `mvn spring-boot:run`
3. `GET http://localhost:8080/api/health`
4. `GET http://localhost:8080/api/jdbc/totals-by-item` — JSON으로 메뉴별 합계
5. `GET http://localhost:8080/api/jdbc/row-count` — `queryForObject` 예시
6. 로그에서 `org.springframework.jdbc.core` 디버그로 **실행된 SQL** 흔적을 본다

---

## 5. 12강·9강과의 관계

- **12강:** `psql`에 직접 타이핑한 SQL과 같은 내용을 **자바 문자열**로 옮긴 것이 `SalesJdbcController`이다.
- **9강:** 같은 Postgres라도 **엔티티·JPA**가 스키마를 만들었다. 13강은 **`schema.sql`**이 스키마를 만든다 — **두 방식이 공존할 수는 있으나**, 이 레슨에서는 혼동을 줄이려 JPA를 넣지 않았다.

---

## 6. 막혔을 때

| 증상 | 확인 |
|------|------|
| 테이블 없음 | `spring.sql.init.mode` 가 `always`인지, DB가 비어 있는 첫 기동인지 |
| 5436 연결 실패 | Docker 컨테이너·포트, `application.yml` URL |

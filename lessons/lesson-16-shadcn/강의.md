## 2) 어떻게 복사했나 (실제 명령)

`lesson-16-shadcn` 폴더에서 아래 순서로 진행하면 된다.

```bash
# 1) Next.js 앱 생성
npx create-next-app@latest lesson-16-shadcn --typescript --tailwind --eslint --app --src-dir --import-alias "@/*" --use-npm --yes

# 2) shadcn 초기화
npx shadcn@latest init --defaults

# 3) blocks 코드 추가
npx shadcn@latest add dashboard-01 --yes
```

이 흐름으로 `src/app/dashboard/page.tsx`와 관련 컴포넌트(`app-sidebar`, `data-table`, `chart-area-interactive` 등)가 자동 생성된다.

## 6) 핵심 학습 포인트

- shadcn은 "라이브러리를 감싸는 조립 패턴"이다.
  - UI 컴포넌트는 shadcn 스타일로 통일
  - 복잡한 인터랙션은 TanStack/Recharts/dnd-kit 같은 전문 라이브러리로 처리
- 대시보드 화면은 보통 "하나의 프레임 안에 여러 상태 시스템"이 공존한다.
  - 차트 상태, 테이블 상태, 사이드바 상태, 드로어 상태 등
- 따라서 실무에서는 "컴포넌트 분해"와 "주석으로 의도 남기기"가 유지보수의 핵심이다.

## 7) 실행 방법

```bash
cd lesson-16-shadcn
npm install
npm run dev
```

브라우저에서 `http://localhost:3000` 접속 시 `/dashboard`로 자동 이동한다.

## 8) 자습 미션

1. `chart-area-interactive.tsx`에서 기본 기간을 `30d`로 바꿔 보고 UX 차이를 기록하라.
2. `data-table.tsx`에서 `Rows per page` 기본값을 20으로 바꾸고, 렌더링 체감을 비교하라.
3. `app-sidebar.tsx`의 메뉴 데이터를 1개 추가하고, 아이콘/라벨/URL 구조를 설명하라.

# 15강 — 풀스택 캡스톤 (최종 정리)

초보 시리즈 **마무리**로, 한 폴더 안에 **PostgreSQL + Spring Boot(API·JWT) + Vite React(Zustand)** 가 한 줄로 이어지는 예제를 둔다.

- **상세 설명·실행 순서:** 이 디렉터리의 **`강의.md`**
- **구조:** `backend/` (Maven), `frontend/` (Vite), 루트 `docker-compose.yml` (Postgres **호스트 포트 5438**)

프론트 개발 서버는 **10강과 동시 실행**을 고려해 **`http://localhost:5174`** 로 고정했다.

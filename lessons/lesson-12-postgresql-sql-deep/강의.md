# 12강 — PostgreSQL 심화 (스타일 A: SQL · `psql` · 실행 계획)

> **위치:** 본 강의 전체는 **`lesson-12-postgresql-sql-deep/강의.md`** 에만 있다.  
> **선행:** 7강에서 `application.yml`의 JDBC URL·Docker Compose를 한 번 다뤘다면 이해가 빠르다. **Java·Spring 코드는 없다.**

---

## 1. 이번 강의에서 배우는 것

- **`psql`** 로 서버에 붙어 대화형으로 SQL을 실행하는 방법
- **스키마·테이블·제약조건(FK, CHECK, UNIQUE)** 이 데이터 무결성에 어떻게 기여하는지
- **`JOIN`·`GROUP BY`** 로 여러 테이블을 묶어 집계하는 패턴
- **인덱스**와 **`EXPLAIN` / `EXPLAIN ANALYZE`** 로 “쿼리가 어떻게 실행되나”를 관찰하는 입문
- **`BEGIN` / `COMMIT` / `ROLLBACK`** 과 트랜잭션의 의미

---

## 2. 왜 7~9강과 따로 두었나

7~9강은 **JPA가 SQL을 대신 생성**해 주는 흐름이 중심이다. 실무에서도 ORM을 쓰지만, **디버깅·성능·리포팅**에서는 원시 SQL과 DB 이해가 필요하다.  
12강은 **DB 엔진 앞에서** 직접 손을 대 보는 단계다. 13강(B)에서 Spring `JdbcTemplate`과 연결한다.

---

## 3. 준비물

| 항목 | 설명 |
|------|------|
| Docker | 이 폴더의 `docker compose up -d` 로 Postgres 16 컨테이너 기동 |
| `psql` | PostgreSQL 클라이언트. 로컬 설치 또는 `docker exec` 로 컨테이너 안의 `psql` 사용 |
| 터미널 | SQL 파일을 `\i` 로 불러오거나 복사·붙여넣기 |

**접속 문자열 (호스트에서):**

```text
postgresql://beanlog:beanlog@localhost:5435/beanlog_lesson12
```

포트 **5435** 는 7강(5432)·8강(5433)·9강(5434)과 겹치지 않게 한 값이다.

---

## 4. `psql` 기본 조작 (처음에 익힐 것)

`psql`에 들어간 뒤:

| 명령 | 의미 |
|------|------|
| `\l` | 데이터베이스 목록 |
| `\c beanlog_lesson12` | DB 연결 전환 |
| `\dn` | 스키마 목록 |
| `\dt lesson12.*` | 스키마 `lesson12` 의 테이블 |
| `\d lesson12.orders` | 특정 테이블 구조 |
| `\q` | 종료 |

SQL 파일 실행 (컨테이너 **밖**에서 프로젝트 루트 기준):

```bash
psql "postgresql://beanlog:beanlog@localhost:5435/beanlog_lesson12" -f sql/01_schema.sql
```

또는 `psql` 안에서:

```text
\i sql/01_schema.sql
```

(경로는 실행 위치에 맞게 조정한다.)

## 5. 따라 하기 (권장 순서)

1. `docker compose up -d`
2. `psql` 로 접속
3. **`sql/01_schema.sql`** 실행 → `lesson12` 스키마와 테이블 생성
4. **`sql/02_seed.sql`** 실행 → 샘플 데이터
5. **`sql/03_select_join.sql`** — 결과가 나오는지 확인
6. **`sql/04_index_explain.sql`** — `EXPLAIN` 출력 읽기(처음엔 “Seq Scan” 등 용어만 짚어도 됨)
7. **`sql/05_transaction.sql`** — 커밋 후 데이터가 남는지, 주석 처리한 실패 실험으로 `ROLLBACK` 을 이해

## 6. 스크립트와 BeanLog 맥락

| 파일 | 내용 |
|------|------|
| `01_schema.sql` | 고객·메뉴·주문·주문줄 — FK·CHECK 로 관계를 명시 |
| `02_seed.sql` | 최소 샘플 행 |
| `03_select_join.sql` | 주문별 매출 집계 예시 |
| `04_index_explain.sql` | 인덱스 + `EXPLAIN` |
| `05_transaction.sql` | CTE로 주문+줄 삽입, 트랜잭션 |

---

## 7. 새로 익히는 용어

| 용어 | 한 줄 |
|------|--------|
| **스키마** | 테이블·함수 등 객체를 묶는 네임스페이스(`lesson12`) |
| **FK (외래 키)** | 다른 테이블의 행을 참조; 잘못된 id 삽입 방지 |
| **트랜잭션** | 여러 문을 하나의 단위로 커밋 또는 전부 취소 |
| **실행 계획** | 옵티마이저가 선택한 조회 방법(순차 스캔, 인덱스 스캔 등) |

---

## 8. 막혔을 때

| 증상 | 확인 |
|------|------|
| 연결 거부 | 컨테이너가 떠 있는지(`docker ps`), 포트가 5435인지 |
| `relation does not exist` | `SET search_path TO lesson12;` 또는 스키마 접두사 |
| `EXPLAIN ANALYZE` 가 너무 단순 | 데이터가 적으면 항상 순차 스캔일 수 있음 — 개념 학습용으로 충분 |

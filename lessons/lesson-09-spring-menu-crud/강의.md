# 9강 — 메뉴 도메인(CRUD) + 권한 + CORS

## 이번 강의에서 배우는 것

- **JPA 엔티티 `Menu`** 와 **Repository**로 Postgres에 메뉴 행을 저장·조회한다
- **`@PreAuthorize("hasRole('ADMIN')")`** 로 쓰기 API만 관리자로 제한하고, **GET 목록은 공개**로 둔다
- 브라우저가 다른 출처(origin)의 API를 부를 때 필요한 **CORS**를 Spring에서 허용한다
- 8강과 동일한 **JWT + 필터** 흐름 위에 **도메인 API**만 얹는다는 감각을 익힌다

## 선행 조건

- 7~8강: `User`, BCrypt 시드, `POST /api/auth/login`, Bearer 토큰, `ROLE_ADMIN`

## PostgreSQL·연동 (7~8강과의 연결)

- **User**는 기존 테이블을 그대로 쓰고, **Menu**는 JPA 엔티티 추가로 새 테이블이 생긴다(`ddl-auto: update`).
- 이 강의용 DB는 **호스트 포트 5434**, DB명 **`beanlog_lesson09`** 로 7·8강과 **볼륨·포트를 분리**해 두었다(강마다 데이터가 섞이지 않게).
- `application.yml` 의 JDBC URL·계정이 컨테이너(`docker-compose.yml`)의 `POSTGRES_*` 와 일치해야 한다.
- **PostgreSQL 자체 입문**(SQL 튜닝·인덱스·권한)은 범위 밖이며, 필요하면 공식 문서·별도 입문서를 본다.

## 8강과의 차이

| 8강 | 9강 |
|-----|-----|
| 인증·관리자 ping 위주 | **`Menu` 테이블 + `/api/menus` CRUD** |
| Postman만 가정 | **React dev 서버 origin**을 위한 **CORS** |

## 새로 등장하는 용어

| 용어 | 설명 |
|------|------|
| **CORS** | 브라우저가 “다른 도메인/포트”의 API에 요청할 때 적용되는 정책. 서버가 `Access-Control-Allow-Origin` 등으로 허용해야 한다. |
| **공개 읽기 / 인증 쓰기** | 카페 메뉴판은 누구나 보고, 수정은 직원만 — API에서도 같은 구조로 나눈다. |

## 코드 지도

| 경로 | 역할 |
|------|------|
| `menu/Menu.java`, `MenuRepository.java` | 엔티티·저장소 |
| `web/MenuController.java` | `GET /api/menus` 전부·단건, `POST`·`PUT`·`DELETE` — 쓰기는 `@PreAuthorize` |
| `bootstrap/MenuSeeder.java` | 초기 메뉴 몇 개(선택) |
| `security/SecurityConfig.java` | `cors` 활성화, `CorsConfigurationSource` 빈에서 `http://localhost:5173` 등 허용 |

## 환경 (Maven)

- **JDK 17** + **Maven**(`mvn`)이 있어야 한다.
- 컴파일만 확인할 때: 프로젝트 루트에서 **`mvn -DskipTests package`**.

## 따라 하기

1. `docker compose up -d` 후 `mvn spring-boot:run`
2. 토큰 없이 `GET /api/menus` — 목록이 보이는지 확인
3. 로그인해 `accessToken`을 받은 뒤 `POST /api/menus`로 항목 추가
4. 토큰 없이 `POST` 또는 잘못된 토큰으로 `DELETE` — 거절되는지 확인

## 10강과 함께 켤 때 (실행 순서)

10강 React는 **이 9강 API가 떠 있는 상태**에서만 동작한다. 터미널을 둘로 나누는 것을 권장한다.

1. **터미널 A (`lesson-09-spring-menu-crud`)** — `docker compose up -d` → `mvn spring-boot:run` (기본 `http://localhost:8080`)
2. **터미널 B (`lesson-10-react-admin-ui`)** — `npm install` → `npm run dev` → 브라우저에서 `http://localhost:5173`

## 막혔을 때

| 증상 | 확인 |
|------|------|
| CORS 에러(브라우저 콘솔) | 서버 `CorsConfigurationSource`에 프론트 origin이 있는지, `SecurityConfig`에 `http.cors`가 켜졌는지 |
| 403 on POST | JWT에 `ROLE_ADMIN`이 있는지, 헤더가 `Bearer ` 형식인지 |
| DB 연결 실패 | `application.yml` 포트(기본 5434)·DB명 `beanlog_lesson09`·컨테이너 기동 여부 |
